These points were read from the public responses or from the existing cost code, not filled in.

- Meteora `/pools/{address}/ohlcv?timeframe=5m` and `/volume/history?timeframe=5m` accept an 8-hour window and return HTTP 400 past that. This run requests 7.5 hours.
- Where a Meteora volume-history row matches a 5-minute timestamp, that row's `fees` field is the LP fee used for the bar.

- Bin step and base fee come from the pool list. The 1% class is base fee from 0.95% up to but not including 1.25%. The other class is base fee at or above 2%. Other fee tiers are left out.
- Exit slippage walks the pool's bins. A non-SOL quote is then sold to SOL at 4 bps against a $10M reserve. Transaction fees use the open and close signature budget. Bin-array rent is charged only for an array other than the active bin's array. Position-account rent is refundable and is not in PnL.
- The decile cutoff for a signal uses only bars before that bar, at most the prior 144 bars (12 hours), and at least 36 bars. The bar is a signal only when its volume/TVL is strictly above that 90th percentile, so a flat tape does not signal. The position opens on the next bar's open. A new signal on the same pool waits until the previous position has closed.

## Inferred

- Neither endpoint publishes 5-minute TVL. Every ratio uses the pool's TVL from the scan that started this run. A pool whose TVL was lower during an older bar looks less extreme, and a pool whose TVL has since fallen looks more extreme.
- Bars without a volume-history fee use base fee plus the current variable fee, times volume, times the pool's observed 24-hour LP share. The variable fee is today's snapshot.
- The path inside a bar is open, the nearer wick, the other wick, then the close. That is the same wick assumption as the other backtests. It is not a swap tape.
- Pool TVL is spread evenly across the assumed bin count when the fee models and the exit walk need a depth. There is no historical bin-array snapshot.
- Holding means buying the volatile token when token X is volatile and token Y is a quote, from the entry price to the exit price. A quote-quote pair has no separate token hold, so versus holding equals versus cash on those events.
- Train is the first 70% of each train coin's bars. The time split is the last 30% of those coins. Holdout coins are the sorted 30% sample-key split and never enter the threshold of another coin. The threshold is per pool.
